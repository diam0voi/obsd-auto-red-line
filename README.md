# obsd-auto-red-line
Native plugin for Obsidian app that adds so-called "red lines"

## How to use:

1. Download repo whichever way you prefer;
2. Simply place folder with repo's content at the `%CURRENT_VAULT_NAME%/.obsidian/plugins/`;
3. Voila!

It has a toggle button in the settings in case you want to automate it for specific purposes by using other extension and such ;3
